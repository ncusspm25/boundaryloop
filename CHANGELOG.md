# Changelog

## 0.1.0 — initial experimental release

- Python CLI and exact-file, versioned task contracts.
- Human-selected Easy/Hard routing; bounded mock and Codex model calls.
- Independent command verification, receipts and focused escalation tickets.
- Local interactive scoped approval, rejection, deferral, revocation and invalidation.
- Transactional state, checkpoint drift detection and idempotent safe resume.
- Local failure fingerprints, optional descriptive capability observations and offline comparisons.
- Installable Codex Skill, parser demos, tests and English/Traditional Chinese documentation.
- Experimental Claude CLI proposal adapter; full runtime-enforced mode remains unsupported.

This is a prerelease-quality controller, not a hardened sandbox. No live cost-saving claim is made.
