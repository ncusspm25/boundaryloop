# Launch checklist

- Run the local release gate, tests, types, formatting, build and clean wheel installation.
- Verify Codex Skill discovery and record actual provider smoke results separately from benchmarks.
- Review tracked paths, staged diff and Git history for secrets, sibling files and private logs.
- Confirm description/topics, license and README installation commands.
- Confirm a new public repository is available; never replace an unrelated existing repository.
- Push only the reviewed commit, verify its GitHub SHA and public visibility.
- Wait for CI results; resolve failures before tagging/releasing.
- Enable private vulnerability reporting and supported public secret protection where available.
- Publish v0.1.0 as a prerelease with honest limits and package hashes; verify the release URL.
- Replace URL instructions in launch drafts only with verified URLs.
- Have the maintainer review and post each community message under its rules. No automated posts,
  fake social proof, bulk cross-posting or claims of savings from mock comparisons.
