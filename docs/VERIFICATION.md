## Review findings fixed during implementation

- Closed SQLite connections explicitly; a context-managed transaction alone retained Windows file
  handles and prevented clean benchmark cleanup.
- Removed a pre-lock byte read that Windows byte-range locking rejected in a second controller.
- Corrected mock file selection after a scoped extension and required real validated response types.
- Made Windows identity use the process token SID, avoiding username/domain ambiguity.
- Rejected excluded snapshot paths, case-insensitive forbidden collisions, Windows devices and
  direct verifier edit targets; rejected NaN/infinite/bool budgets.
- Skipped pip-generated bytecode when installing packaged Skill resources. A source-only test
  did not reveal this; the clean wheel installation did. A focused regression test now covers it.
- Invalidated outstanding approvals on blocked context changes and removed cancelled cards from
  the pending queue. Local interruption stops the run without an automatic architect call.

Full runtime enforcement, native conversation recovery, semantic policy proofs, real Claude calls,
hard currency caps and comparative live benchmarks remain unsupported/experimental as documented.
